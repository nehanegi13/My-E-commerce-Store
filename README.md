# 🛒 My E-Commerce Store

A modern E-commerce web application built using React and Redux Toolkit.  
Users can browse products, filter items, view product details, and add items to the cart.

---

## 🚀 Features

- 🛍 Product Listing
- 🔍 Category Filtering
- 📊 Sorting Options
- 🛒 Add to Cart Functionality
- 📦 Product Detail Page
- ⚡ State Management using Redux Toolkit
- 💻 Responsive UI

---

## 🛠 Tech Stack

- React.js
- Redux Toolkit
- React Router
- JavaScript (ES6)
- CSS3
- Create React App
